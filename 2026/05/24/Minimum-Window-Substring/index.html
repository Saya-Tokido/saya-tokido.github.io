76. Minimum Window Substring - LeetCode

2. Problem Description

Given two strings s and t of lengths m and n respectively, return the minimum window substring of s such that every character in t (including duplicates) is included in the window. If there is no such substring, return the empty string "".

The testcases will be generated such that the answer is unique.

Example 1:

  • Input: s = "ADOBECODEBANC", t = "ABC"
  • Output: "BANC"
  • Explanation: The minimum window substring "BANC" includes ‘A’, ‘B’, and ‘C’ from string t.

Example 2:

  • Input: s = "a", t = "a"
  • Output: "a"
  • Explanation: The entire string s is the minimum window.

Example 3:

  • Input: s = "a", t = "aa"
  • Output: ""
  • Explanation: Both ‘a’s from t must be included in the window. Since the largest window of s only has one ‘a’, return empty string.

Constraints:

  • m == s.length
  • n == t.length
  • 1 <= m, n <= 10^5
  • s and t consist of uppercase and lowercase English letters.

Follow up: Could you find an algorithm that runs in O(m + n) time?

3. Core Idea

  • Approach: Sliding Window (Variable Size) + Frequency Counter.
  • Mechanism:
    • We use a vector need of size 128 to record the remaining count of each character required to cover t. Initially, need[c] stores the frequency of character c in t.
    • A counter missing tracks the total number of characters still needed to form a valid window (initialized to t.size()).
    • We expand the window using a right pointer. For each character s[right]:
      • If need[s[right]] > 0, it means this character is genuinely needed, so we decrement missing.
      • We then decrement need[s[right]] (values can become negative, indicating excess characters in our current window).
    • When missing == 0, the current window is valid. We enter a while loop to shrink it from the left to find the optimal minimum length:
      • Record and update the minimum substring found so far.
      • Slide the left pointer inward. We increment need[s[left]]. If need[s[left]] > 0, it means we just threw out a critical character, so we increment missing to break the validation loop.
